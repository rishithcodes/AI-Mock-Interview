# AI Mock Interview Platform 🎯

An AI-powered mock interview platform that simulates real interview experiences using **Google Gemini**, **speech recognition**, and **text-to-speech**, providing candidates with realistic interview practice and post-interview performance evaluation.

## 🚀 Features

### 👨‍💼 AI Interviewer
- Domain-specific interview questions (e.g., AI/ML, Backend, Frontend, etc.)
- Questions generated dynamically based on:
  - Candidate’s resume
  - Previous conversation context
- Ensures **no repeated questions** and progressive topic coverage

### 🗣️ Voice-Based Interaction
- **Speech-to-Text** for answering questions verbally
- **Text-to-Speech** for AI interviewer responses
- Seamless hands-free interview experience

### 🧠 Smart Question Flow
- Prevents repeated or generic questions
- Automatically switches topics (technical, scenario-based, problem-solving)
- Handles clarification requests professionally

### 📊 Performance Evaluation
- Post-interview evaluation using AI
- Scores generated in percentages for:
  - Technical Skills
  - Soft Skills
  - Problem-Solving Ability
- JSON-based evaluation output for easy visualization

### 🔐 Interview Integrity 
- Designed to support:
  - Eye detection
  - Tab switching detection

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- Tailwind CSS

**AI & NLP**
- Google Gemini API
- pdfjsLib 

**Speech**
- Web Speech API (Speech Recognition)
- Speech Synthesis API (Text-to-Speech)
